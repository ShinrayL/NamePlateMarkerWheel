
# 📋 插件项目需求文档

## 一、项目概述

| 项目信息 | 内容 |
|---------|------|
| **插件名称** | NamePlateMarkerWheel (暂定) |
| **核心功能** | 双击姓名板弹出径向标记轮盘，快速设置团队标记 |
| **适用版本** | WoW 12.0+ (至暗之夜/Midnight) |
| **开发语言** | Lua + XML |
| **预计工期** | 2-4周 |

## 三、技术实现方案

### 🔧 核心API

```lua
-- 设置团队标记 (index: 1-8, 0为移除)
SetRaidTarget("unit", index)

-- 获取单位信息
GetUnitName("unit")
UnitExists("unit")

-- 姓名板相关
C_NamePlate.GetNamePlates()  -- 获取所有姓名板
namePlate.unit  -- 姓名板关联的单位
```

### 📁 文件结构

```
NamePlateMarkerWheel/
├── NamePlateMarkerWheel.toc      # 插件描述文件
├── Core.lua                      # 核心逻辑
├── WheelUI.lua                   # 轮盘界面
├── Config.lua                    # 配置管理
├── Events.lua                    # 事件处理
└── Media/
    ├── textures/                 # 标记图标纹理
    └── sounds/                   # 可选音效
```

### 🎨 轮盘UI设计

```lua
-- 径向布局计算示例
local function GetWheelPosition(index, centerX, centerY, radius)
    local angle = (index - 1) * (360 / 8) * math.pi / 180
    local x = centerX + radius * math.cos(angle)
    local y = centerY + radius * math.sin(angle)
    return x, y
end
```

## 四、⚠️ 12.0版本注意事项

根据搜索结果，**12.0至暗之夜版本对插件API有较大限制**：

| 限制项 | 影响 | 解决方案 |
|-------|------|---------|
| 战斗API加密 | 部分战斗数据无法访问 | 本项目不涉及战斗数据，影响较小 |
| 安全代码限制 | 某些操作需在安全环境下执行 | `SetRaidTarget` 是安全API，可直接调用 |
| 姓名板自定义 | 部分姓名板修改受限 | 只监听事件，不修改姓名板本身 |
| 插件通讯加密 | 插件间通讯受限 | 本项目为单体插件，无影响 |

✅ **好消息**：标记功能 (`SetRaidTarget`) 是**安全API**，不受战斗限制影响！

## 七、潜在挑战与解决方案

| 挑战 | 解决方案 |
|------|---------|
| 双击与单击冲突 | 使用计时器区分单击/双击 |
| 轮盘位置超出屏幕 | 添加边界检测，自动调整位置 |
| 多姓名板重叠 | 只响应最上层姓名板 |
| 战斗中被限制 | 确认API安全性，必要时添加提示 |
